## 更可靠的风格归纳

### 阅读结构比统一画风更稳定

这些样本反复出现左上 Olares 标识、左侧粗标题和右侧主题焦点。浅色版使用深色字，深色版使用白字；Logo 与标题有共同的左侧对齐线和足够距离。不要机械固定左右五五分：文字长短和主视觉大小会改变占比。

标题多为 1–3 行，常保持统一字重。FlowStudio、Router、Note 把产品名及收益句纳入同一个大标题块；这不要求为新文章另写副标题，也不说明三行对任何标题都合适。用户当前确认的文案与偏好优先。

### “简洁”是焦点少，不是材质少

样本包含透明体、玻璃环、金属边、反射、光束和暗色科技场景。有效的共性是细节集中在主题区域，标题背后较安静，主角在缩略图上仍可辨认。不能把此前某张金属卡匣被否定，升级成 Olares 禁止玻璃/金属/3D 的规则。

也不能反向规定所有封面必须做 3D。Intel 的点阵和 Open Source 活动的照片说明，视觉语言由内容决定。已认可的纯图形背景、真实界面方案继续适用。

### 插画和背景需要共同构图

Voice、FlowStudio、Router 的主体通过反射、回染和方向一致的光线融入环境。留白不是给画面切出一块纯白矩形；背景可以连续延伸到标题后方，只要局部对比与细节密度不干扰阅读。

在生成提示词中说明主体与环境的光照关系、重点区域和文字安全区。后置官方标识时保留其正确形状，不为了模拟立体感让模型重新绘制 Logo。若场景透视使标识难以正确嵌入，简化承载面或调整视角。

## 实测排版：Voice 两个尺寸

来自浏览器 Figma 属性面板，不是目测或正式设计 token：

| 属性 | 宽版 | 社媒版 |
| --- | --- | --- |
| 画板 | 1800 × 600 | 1600 × 900 |
| 标题 | Introducing Voice，一行 | Introducing / Voice，两行 |
| 字体 / 字重 | Poppins / Bold | Poppins / Bold |
| 字号 | 80 px | 90 px |
| 行高 | 96 px | 110 px |
| 字距 | −1 px | −1 px |
| 文本框 x / y | 82 / 272 | 82 / 340 |

宽版 Olares 标识的选中矢量边界约为 203.32 × 47.87；这是该节点的实际尺寸，不是所有 Logo 的统一尺寸规范。Intel 标题属性显示混合字体/字号，不能把 Voice 的参数推广到整套文件。

两个 Voice 版本的画面比例、主体尺度、标题换行和字号均发生变化，说明适配应重新构图，不能拉伸宽图或仅加上下边。保留主题和视觉气质，重新检查当前尺寸下的可读性与裁切。

## 后续使用方式

按文章选最接近的参考类型：应用发布看 Voice / FlowStudio / Note，关系解释看 CLI / Password，活动看 Intel / Open Source。新设计前从相近样本抽取构图和素材组织原则；不要直接复制主题物件、配色或把所有文章做成同一张模板。

复核优先读取 Figma 连接器；额度或能力不足时可只读浏览器，并据实说明无法取得的结构信息。浏览器视觉观察不能代替未读到的字体、图层或发布日期数据。参考页面变化后，更新有变化的结论即可。
