## Adding a type

1. Collect one or two external reference articles and one or two Olares posts.
2. Break each into its paragraph skeleton and the job of each paragraph.
3. Write `<type>.md` with: when to use, skeleton table, references with what to keep and drop, an approved Olares sample once one exists, and questions to settle before drafting.
4. Add a row here and in the type table in `SKILL.md`.
